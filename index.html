How answers are made

Your question is turned into a vector and compared with every passage. The best sentences from the closest passages are quoted back, each with its page. Quote mode returns extracted sentences. Optional written answers can be wrong, so verify every claim. A similarity threshold can miss relevant text or return unrelated passages. It cannot reason across pages or do arithmetic; it finds and quotes.

Document text and questions are processed in this browser, not posted by the app to a server. PDF/model libraries load from jsDelivr, Hugging Face and model CDNs; those providers receive network metadata. Third-party code runs here, so do not use this demo for confidential or untrusted documents.

Search downloads a local model on first use. Optional writing requires WebGPU and a much larger download, can use significant memory, and can invent details. Reset cancels document search; a browser tab reload stops all work.
